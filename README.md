## 📌 About the Project

**Case Zero** is an interactive, data-driven investigation game developed using Flask. Players take the role of an investigator and solve different cases by analyzing evidence, examining clues, identifying suspects, and using logical reasoning.

The game combines investigative storytelling with data analysis to create an engaging and challenging gameplay experience.

---

## 🎮 Features

- Multiple investigation cases
- Sequential case unlocking system
- Interactive case selection interface
- Evidence and clue-based gameplay
- Suspect investigation
- Data-driven reasoning and analysis
- Case progress tracking
- Master case with advanced difficulty
- Responsive and user-friendly interface
- Flask-based backend
- Organized case and game-engine structure

---

## 🕵️ Gameplay

1. Open the live application.
2. Select an available investigation case.
3. Read the case description carefully.
4. Examine the available evidence and clues.
5. Analyze the information and identify important connections.
6. Investigate suspects and possible motives.
7. Submit your conclusion.
8. Unlock and solve the next case.

Each case becomes progressively more challenging and requires careful observation, reasoning, and analytical thinking.
